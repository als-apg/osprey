Web terminal: the **Pop out** button in a tile's header now moves the tile's
content into a window that stays attached to the terminal, for the agent pane
too. The tile keeps its place and shows **Bring back**; closing the window or
reloading the terminal puts the content back. The standalone page is now
**Open in new window** on the panel's menus and in the command palette. The
agent pane's Export button moved to its tile menu as **Export conversation**.
