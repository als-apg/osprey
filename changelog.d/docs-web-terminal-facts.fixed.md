The web-terminal guides now match the code in several places a reader acts on. Running the multi-user stack from a source checkout needs `--dev` on both `osprey build` and `osprey up` (or `osprey up --build --dev`); `osprey up --dev` alone refuses a render built without it. Sign out is the sidebar-footer row, not an item in the More menu. Panels discovered from disk run at an opaque origin, not the terminal's own. The lattice status is spelled `not_computed`. The multi-user config block is marked as an excerpt of the preset and shows its `auth:` lines. The roster and login snippets are written in the `profile.yml` form, `config:` with one dotted `modules.web_terminals:` key, because a nested `modules:` block there replaces the whole rendered `modules` subtree. The CANOPY pages' sections now nest under their titles. A new docs test holds the quoted refusal lines, environment names, message types, stylesheet paths, theme names, lint codes, figure statuses and preset excerpts to their definitions in the source.
