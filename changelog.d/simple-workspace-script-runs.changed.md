In the Simple view's workspace, the records of a script run (the
Pre-Execution Review, the run's notebook and its result record) no longer take
the large result card. The card keeps showing the newest plot, file or other
result, and the run records are listed under a folded "Script runs" group below
the results. You can still open a run record from that group or from a link in
the chat. The Expert view is unchanged.
