The OPTIMIZER panel has a runs list, a stage and an inspector. A run goes
from its set-up, or the agent's draft, to a review where Start runs exactly
the stored revision shown, then to a run page with Pause and Cancel, and ends
on an outcome that says what the run left on the machine. A run that waits
for its write approval shows `waiting for approval` and says who approves it
and where. Past runs open from the list or from a table of all stored runs.
Times show on the facility clock, and Today and Yesterday in the runs list
follow the facility calendar; the start of a stored run shows as the service
wrote it.
