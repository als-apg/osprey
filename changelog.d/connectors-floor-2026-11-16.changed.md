The framework, `osprey-facility`, `osprey-optimizer` and `pyaml-cs-osprey` require `osprey-connectors>=2026.11.16`, the first release whose simulator serves a status that leaves its idle value for a stated time after a write to its command (`responds`) and moves a readback when its start command is written (`started_by`), and that carries `osprey_connectors.command.fire`. Against an older release a facility that states `responds` would build and its status would never leave idle.
