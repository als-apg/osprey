**Breaking change:** `osprey-connectors` declares its public API. Every public
module lists its names in `__all__`, and a name it does not list now starts
with an underscore. The `control_system`, `archiver`, `simulation` and `ipc`
subpackages hide their implementation modules behind an underscore
(`control_system/epics_connector.py` is now `control_system/_epics_connector.py`,
`simulation/engine.py` is now `simulation/_engine.py`) and export their public
names from the subpackage itself. The old module paths are not kept as aliases.

- Import connector-contract, archiver, simulation and connector-host names from
  `osprey_connectors.control_system`, `.archiver`, `.simulation` and `.ipc`.
  Build a concrete connector through `ConnectorFactory` from its type name; a
  registry that needs the built-ins by module path takes them from
  `osprey_connectors.factory.BUILTIN_CONNECTORS`. `type:` values in
  `config.yml` are unaffected.
- The `osprey.connectors.control_system.*_connector`,
  `osprey.connectors.archiver.*_archiver_connector` and
  `osprey.simulation.{engine,machine,series,expressions,procedural,archiver_seed}`
  paths are removed. The other historical `osprey.*` paths still import, for
  code outside the framework, and `osprey.connectors.control_system.base`,
  `.limits_validator`, `osprey.connectors.archiver.base` and `._timerange` are
  the same module objects they always were.
- Names that move or change: the per-call timeout keys are in the new
  `osprey_connectors.call_timeout`; `posture_store.STATE_DIR_NAME` is
  `CONTROL_STATE_DIR_NAME` (and `control_context` no longer re-exports it);
  `types.SIMULATED_TYPES`, `identity.usable_identity`,
  `ipc.config_writes_enabled`, `posture_store.NoOwner` and
  `ControlSystemConnector.current_value_reader()` lose their underscore;
  `DEFAULT_VA_PORT` is in `osprey_connectors.types`; the MongoDB store's
  `address_overrides`, `mongo_client_kwargs` and `CA_FILE_ERRORS` are exported
  from `osprey_connectors.archiver`.
- Module-level names that were neither listed nor needed outside the package
  are now private, among them `config.config_flag`,
  `control_context.invalidate_cache`, `posture_store.StoreVerdict` and
  `types.writes_enabled_key`.
- The package ships a `py.typed` marker, and the lint job now fails if the
  framework imports past these namespaces or through a historical path, or if
  the package imports `osprey`.
