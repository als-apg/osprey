ARIEL hybrid search under `strategy: rrf` no longer loses its answer, or hides the loss, when one text lane is down: a semantic lane that fails for any reason (unreachable embedding provider, model error, timeout) returns the keyword ranking with a warning naming the cause, a qmd sidecar that is down or fails the query returns the semantic ranking with a warning naming the sidecar, and only both lanes down is an error, naming both. Semantic search itself now reports a failed query embedding as a search error naming the provider and cause, instead of an empty result that read as "no matches".
