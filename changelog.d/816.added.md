`bluesky.external:` — external-worker mode for the plan lane. The bridge, bluesky-web sidecar, and MCP server deploy as usual but attach to a facility-run bluesky-queueserver (`zmq_control_addr`, CURVE key via an operator-named `.env` variable or an explicit `insecure_plaintext: true`) and read the facility's Tiled (`tiled_uri`/`tiled_api_key_env`) instead of deploying a queueserver, Redis, and Tiled of their own. Environment ownership follows: an external worker's environment is never opened, closed, or rebuilt by the bridge.
