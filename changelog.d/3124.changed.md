An application's `vendor:` entry may carry its version in a directory of `into`
instead of the file name (`panel/vendor/pdfjs-6.5.438/wasm/jbig2.wasm`), so a
library that loads sibling files by fixed names can be declared. The version
still counts only as a whole token of one path component, and an entry whose
`into` carries it nowhere is still refused.
