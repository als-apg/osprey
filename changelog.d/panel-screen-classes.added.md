`osprey facility panels write` states each screen's class in `index.json`, so a reviewer judges one standard screen per class and reads how the other members differ. A device's card is classed by its device class, card recipe and the set of signal roles it shows; a set by its members' device types; every other screen is its own class. Sameness is measured on what a screen shows, not on its pixels. Each entry names its `class` and, when it is off its standard, `differs` in words (a fact or section missing, another number of rows or blocks, a label cut to fit); the `classes` table holds each class's key, standard, counts and a layout hash that tells a changed standard. `panels check` reports a stale class as `stale_class`, and the new `osprey facility panels classes` prints the table and a one-line summary. The panels format is 2.
