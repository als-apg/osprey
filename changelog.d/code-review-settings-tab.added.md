The Settings drawer has a Review tab: whether code review is on, its time limit, and the code reviewer's rules (`code_review.prompt`), read-only. An admin-tier terminal can turn code review off there until it restarts, like the safety watchdog; each move and each skipped review is audited. It says what reviews do while the rules file cannot be used, and an empty rules file now counts as missing. The rules no longer appear under Safety.
