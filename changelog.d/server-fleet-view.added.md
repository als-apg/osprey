Channel Finder: with `channel_directory.fleet` configured, the server fleet service reads every IOC's liveness PV once per refresh period and the panel's **IOCs** view and the `server_fleet` tool list each IOC's state (`alive`, `stalled`, `silent`, `unreached`, `unknown`) and findings from that snapshot. Roster sources (`channel_directory.fleet.roster_sources`, public, not yet stable) add expectation findings on `live`, and the `stopped_servers` scenario key stops a simulated IOC; the demo ships `line-server-stopped`. With the fleet on, the IOC page and `server_record` take an IOC's alive answer from the snapshot, so it can be up to one refresh period old; the read time is shown.
