**Breaking change:** `osprey build`, `osprey validate` and `osprey facility validate` stop with one `profile-invalid` line when a profile, a persona, a host variant or a `--set` edit states `control_system.limits_checking.database_path` (or a per-type `…limits_checking.database_path`). The limits database is always the one the build renders from `data/facility/limits.yaml`. To upgrade, write the old table's records into `data/facility/limits.yaml`, delete the key from the profile and delete the old table file.
