A panel a profile does not select no longer renders as a tab. The `web_panels` selection is now projected as `enabled` onto every `web.panels.<id>` block a render carries — the facts a persona inherits for a tab it excluded, and the blocks an injector writes into a deploying render for a tab only its personas select, included — and one shared predicate (`panel_spec_enabled`) reads it in the web terminal, the health probe and the credential grants, so custom panels honour `enabled: false` like builtins. An authored `web.panels.<id>.enabled` that contradicts the selection is refused at validation, and `default_panel` / `panel_presets` must name a selected (or universal) panel.
