The example facility's booster `BR` has a physics model: a static periodic
deck of the 75 m ring (24 bends, 32 quadrupoles, 32 correctors, 20 BPMs) and
a measurement file, so the simulator serves `[BR, BTS, LTB, SR]` and the
booster's BPM positions read its closed orbit. The graph example `q1c` lists
up to 1000 devices, since the example now holds 537 magnets.
