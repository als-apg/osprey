A value display in a generated panel is as wide as the widest text the facility states it can show: its longest state word (the facility file's `options`, or `state_labels.csv`), else the longer of its limits as the display prints them when that is wider than the stand-in, else the stand-in `-0.00123`, the widest number three significant digits print, since nothing stated bounds the value. The unit is added where the display prints it. The panel graph now reads each channel's `options` and limits record. Every text label's box is at least one line of the viewer's font high (the line height is read from the font file with the advance widths), grown about its middle where it was lower, so a light's "?" mark and a 13 px label in a short box are drawn at the size the file states.
