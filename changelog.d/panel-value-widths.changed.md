A value display in a generated panel is as wide as the widest text the facility states it can show: its longest state word (the facility file's `options`, or `state_labels.csv`), else the longer of its limits as the display prints them when that is wider than the stand-in, else the stand-in `-0.00123`, the widest number three significant digits print, since nothing stated bounds the value. The unit is added where the display prints it. The panel graph now reads each channel's `options` and limits record.
