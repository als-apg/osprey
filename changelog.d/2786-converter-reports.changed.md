The HTML-to-image converter no longer downloads Chromium at run time. A missing browser is reported as `dependency_missing` with the install command by `artifact_export` and ARIEL `entry_create`, and with the same text by the gallery's logbook draft. A host that relied on the download installs the browser once with that command; container images get it from the image build. A missing Playwright package is no longer answered with a second install command: it is a dependency of OSPREY, and its absence is reported as an import error.
