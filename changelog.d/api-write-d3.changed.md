`target_state.publish_last_switch(progress)` takes a `SwitchProgress` and drops `expires_in_s`. Build the progress with `target_state.switch_applying(generation, bound_s=...)`, `switch_applied(generation)` or `switch_failed(generation, reason=..., detail=...)`. The report file is now read, evolved and rewritten through `control_context.write_report`. A report that does not parse is no longer merged into. Served JSON keys are unchanged.
