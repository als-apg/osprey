CI runs six single-module e2e lanes as cells of the existing matrix jobs: the optimizer deploy, execution-environment parity, deploy write-back, notebook panel and graph reseed lanes are `stack-e2e` cells, and the control-target switch lane is a `va-live-e2e` cell. Matrix cells are named after their class (`Stack E2E — Optimizer Deploy`, `Live VA E2E — target-switch`), so a skipped matrix still says which class skipped.
