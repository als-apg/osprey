Dev image builds no longer re-resolve every third-party dependency on every commit. `--dev` renders now pin the deps layer to the base release the checkout descends from (cache-stable across commits; the staged wheel still overlays the code), instead of the per-commit dev version whose changing value busted the layer cache in every image — and whose PyPI pin could never install anyway, falling back to *latest*, which can sit ahead of the checkout's lineage. A source-change rebuild cycle drops from tens of minutes per image to seconds.
