`phoebus_open_panel` takes an optional `macros` argument, a mapping of macro
name to string value, so the agent can open a parameterised Phoebus display
(`{"IOC": "injbpm"}`). A value is a plain token: one that is empty or contains
`$(`, `${`, `/`, `\`, `..`, `:`, whitespace or a control character is refused.
Macros need a Phoebus agent bridge that reads the `macros` field of
`POST /open`; without the argument the request is unchanged.
