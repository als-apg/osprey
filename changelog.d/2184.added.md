`phoebus_open_panel` takes an optional `macros` argument, a mapping of macro
name to string value, so the agent can open a parameterised Phoebus display
(`{"IOC": "injbpm"}`). A value is a plain token (ASCII letters, digits, `.`,
`_`, `-`), so it cannot leave the display's directory; it still selects among
sibling files where a display builds a file name from a macro, and a macro
passed this way overrides a Phoebus preference macro of the same name. A
Phoebus agent bridge too old to apply macros is refused with `not_supported`;
without the argument the request is unchanged.
