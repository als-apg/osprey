The Sessions row has a view button beside "+". Its menu filters the session list by last activity (today, 3, 7 or 30 days, or all), groups it by date or by state (sessions open now, then the others), shows only the sessions that have artifacts, and turns the artifact counts on or off. "Reset to defaults" restores the list. The choices are kept in the browser for each user, and a dot on the button shows that the list is not at its defaults. The session in use is always shown. Each row that opens a submenu shows its current choice, through a new `value` field of the shared context menu. The item that groups a session's artifacts is now "Artifacts by ▸ Activity / Kind" in this menu and in the Sessions row's right-click menu (before: "Group by ▸ Kind / Activity"), so that "Group by" always means the sessions.
