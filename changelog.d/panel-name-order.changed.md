Every list of the panels ordered by name takes the numbers in a name by value, so outputs read 0, 1, 2, 10, 11 and never 0, 1, 10, 11, 2; one helper, `osprey.facility.panels.order.name_order`, orders them all. On an operate panel the kind's tag stands once at the head of a run of one kind, a row whose button says its name has no name beside it, and a choice whose segments wrap reads downward like an action group.
