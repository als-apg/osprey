A link box drawn over a cut label now carries the label's whole text as its tooltip (with the link's own label first where the text does not hold it); a box over several cut labels joins their whole texts one per line, and counts the rest past 24 lines. Before, the box the pointer reaches showed only the link's label, so a rack unit cut to "<device> · contested…" showed only the device id. Measuring text in the viewer's font (since the font metrics change) also changes which values on a place strip get a lane, so a strip may show other values than before; each one not shown is still counted in its "values not shown" line.
