The framework, `osprey-optimizer` and `pyaml-cs-osprey` require `osprey-connectors>=2026.11.13`, the first release that lists a directory's servers, stops a simulated server and reads the `channel_directory` section under that name. The directory, alarm and put-log service connectors the channel directory reads came with 2026.11.12. Framework 2026.11.0 was published with the floor at 2026.11.11, where the channel directory answers unavailable: `pip install -U osprey-connectors` repairs an existing install.
