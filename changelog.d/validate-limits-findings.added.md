`osprey facility validate` reports two limits findings on stderr: the setpoints with no limits record, which the target serves writable with no range when its limits mode is `optional` and refuses otherwise, and the limits records that state only one edge, which are served not writable. Each finding is a count line and its addresses, the first ten unless `--all-limits` is given. The findings change nothing: what is served and the exit code stay as they were.
