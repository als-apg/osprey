The Jupyter tile has a **Reload** icon on its bar, and its **⋯** menu has
**Restart kernel server** and **Show server log**. Restart asks first, because
running kernels stop. While JupyterLab starts, the tile shows "Starting
JupyterLab…". If JupyterLab does not start, the tile shows the reason and a
**Retry** button.
