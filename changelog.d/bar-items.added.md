The web terminal's header and status bar can now be rearranged. **Customize
bars** — from a right-click on either bar, the display menu, or the command
palette — opens a sheet you drag items from into either bar, between the two,
or out again, with the options an item has (a UTC clock, the width of a gap),
three stock presets and a switch for hiding the status bar. While you are
editing, a right-click on either bar also offers a reset back to the
deployment's own arrangement. A few items can be moved but never removed, and a
deployment can lock more.
Customizing needs Expert mode; Simple mode renders the saved arrangement.
