Add the mml layer's seed-once pass, `osprey.facility.layers.mml.seed`, run by the layer's importer after it writes its records: each authored file that does not exist yet is created with a header line and never rewritten afterwards. `limits.yaml` holds each setpoint's band as its export's `Range` states it, with `writable: true` on the setpoints a model wires; `seeds.yaml` holds the export's nominal of each channel no model wires, and the import prints `golden skipped: <n> wired channels`; `measurement/<model>.yaml` holds each wired model's groups, instruments, allowed measurements and pyAML's step and settle keys; `classes.yaml` holds one row per mapping class the vocabulary lacks; `identity.yaml` holds the mapping's `facility:` block, which is then removed from `mapping.yaml` with every other line of the mapping left as written. A band is never widened to reach a nominal. A wired setpoint whose `Range` states no finite band on both edges is not made writable, and the import prints `limits unbanded: <address> export [lo,hi]` for it. When `limits.yaml` exists, the import prints `limits differ: <address> file [lo,hi] export [lo,hi]` for each record whose band is not the export's and changes nothing. The importer writes an address any `write` field names as a setpoint, whichever family field named it first, so such a setpoint carries a limits record too.
