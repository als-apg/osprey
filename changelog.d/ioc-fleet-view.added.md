Channel Finder: with `pv_directory.fleet` configured, the IOC fleet service reads every IOC's liveness PV once per refresh period and the panel's **IOCs** view and the `ioc_fleet` tool list each IOC's state (`alive`, `stalled`, `silent`, `unreached`, `unknown`) and findings from that snapshot. Roster sources (`pv_directory.fleet.roster_sources`, public, not yet stable) add expectation findings on `live`, and the `stopped_iocs` scenario key stops a simulated IOC; the demo ships `line-ioc-stopped`. With the fleet on, the IOC page and `ioc_record` take an IOC's alive answer from the snapshot, so it can be up to one refresh period old; the read time is shown.
