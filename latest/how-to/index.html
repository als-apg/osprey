How-To Guides#

Task-oriented guides that walk you through common OSPREY operations step by step. Each guide focuses on a single goal and assumes you already have a working OSPREY installation. The sections follow the natural journey: build and deploy a project, operate the agent day to day, then work with the bundled facility services.

Build Profiles

Build a facility-specific assistant from a profile you own — convention directories, taking ownership of framework artifacts, personas, and secrets.

Build Profiles
Deploy a Facility

The end-to-end walkthrough: one deployment repo from osprey init through the CI scaffolding to a running three-service stack.

Deploy a Facility
Container Deployment

The service stack behind a running project — compose templates, networking, the environment chain, and the agent’s own container image.

Container Deployment
LLM Providers

Pick the provider that drives the Osprey agent and map the model tiers each one serves, including open-weight and self-hosted models behind the translation proxy.

LLM Providers

Operate#

Web Terminal

The browser cockpit for the Osprey agent — launching and theming it, adding your own side panels, reporting problems from inside it, and serving a whole team from one host.

Web Terminal
Agent Interfaces

The CLI agent, event-driven dispatch, external MCP servers, and chat bridges — the four ways to reach the agent.

Agent Interfaces
Health and Monitoring

Is it up, and what is it doing — facility health checks you can extend, plus the agent’s own logs and metrics over OTLP.

Health and Monitoring
Control Systems

Connectors for your control system, the virtual accelerator to rehearse on, switching to the live machine, and what the agent may not touch.

Control Systems

Facility Knowledge
