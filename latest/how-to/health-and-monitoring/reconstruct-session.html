Reconstruct a Session#

The telemetry store keeps two records of every agent session: the events the agent harness emits (prompts, responses, API calls) in otel_logs, and the records its tools file in audit_ledger. One query puts them back together in the order they happened, and any configured reader can run it.

For what the store holds and how it is fed, see Monitor Your OSPREY Agent; for how long it keeps it, see Keep the Agent Record.

What you need#

  • A reader key. Every entry under services.telemetry_store.readers gets a key that osprey up writes to .env.telemetry-reader.<name> at the repo root (mode 0600, one line password=<key>). The account name is the reader’s name.

  • The store’s host port. The store answers HTTP on loopback at deployment.port_base + 804 (http://127.0.0.1:10804 at the default port base), or at services.telemetry_store.port when that is set.

  • Whose session, and which. The user name the session was recorded under and its session id. To list a user’s recent sessions:

    SELECT SessionId, min(Timestamp) AS started, count() AS events
FROM telemetry.otel_logs
WHERE User = 'alice' AND Timestamp > now() - INTERVAL 3 DAY
GROUP BY SessionId
ORDER BY started DESC

The query#

-- Reconstruct one agent session as a reader: every prompt, response and other
-- agent event, every tool call, the approvals that answered them, and the
-- queueserver preflight checks run on the user's behalf, in the order they
-- happened. A tool call is placed where it started (its Timestamp less
-- duration_ms). Long values are cut to 4096 characters.
--
-- A reader's result is capped at 1000 rows, so the recipe pages by keyset.
-- Send it by POST with the parameters param_user, param_session and the
-- cursor: the first page takes param_after_at=2000-01-01 00:00:00,
-- param_after_source= (empty) and param_after_hash=0; every next page takes the
-- last row's at, source and row_hash. A page of fewer than 500 rows is the last.
WITH
    (
        SELECT min(Timestamp)
        FROM telemetry.otel_logs
        WHERE User = {user:String} AND SessionId = {session:String}
    ) AS session_start,
    (
        SELECT max(Timestamp)
        FROM telemetry.otel_logs
        WHERE User = {user:String} AND SessionId = {session:String}
    ) AS session_end
SELECT at, source, row_hash, user, kind, tool_use_id, terminal_session, detail
FROM
(
    SELECT
        Timestamp AS at,
        'event' AS source,
        cityHash64(Body, toJSONString(LogAttributes)) AS row_hash,
        User AS user,
        toString(Event) AS kind,
        '' AS tool_use_id,
        TerminalSession AS terminal_session,
        substring(toJSONString(LogAttributes), 1, 4096) AS detail
    FROM telemetry.otel_logs
    WHERE User = {user:String} AND SessionId = {session:String}

    UNION ALL

    SELECT
        Timestamp - toIntervalMillisecond(toInt64(toFloat64OrZero(LogAttributes['osprey.audit.duration_ms']))),
        'tool_call',
        cityHash64(Body),
        User,
        toString(Surface),
        ToolUseId,
        TerminalSession,
        substring(Body, 1, 4096)
    FROM telemetry.audit_ledger
    WHERE User = {user:String} AND SessionId = {session:String}

    UNION ALL

    SELECT
        Timestamp,
        'approval',
        cityHash64(Body),
        User,
        LogAttributes['osprey.audit.decision'],
        ToolUseId,
        TerminalSession,
        substring(Body, 1, 4096)
    FROM telemetry.audit_ledger
    WHERE User = {user:String}
        AND SessionId = ''
        AND ToolUseId IN (
            SELECT ToolUseId
            FROM telemetry.audit_ledger
            WHERE User = {user:String} AND SessionId = {session:String} AND ToolUseId != ''
        )

    UNION ALL

    SELECT
        Timestamp,
        'preflight',
        cityHash64(Body),
        User,
        LogAttributes['osprey.audit.decision'],
        ToolUseId,
        TerminalSession,
        substring(Body, 1, 4096)
    FROM telemetry.audit_ledger
    WHERE Surface = 'preflight'
        AND OnBehalfOf = {user:String}
        AND Timestamp >= session_start - INTERVAL 60 SECOND
        AND Timestamp <= session_end + INTERVAL 60 SECOND
)
WHERE (at, source, row_hash) > ({after_at:DateTime64(9)}, {after_source:String}, {after_hash:UInt64})
ORDER BY at, source, row_hash
LIMIT 1 BY at, source, row_hash
LIMIT 500

Every value is a typed parameter, never text spliced into the SQL, so a user name or session id with a quote in it is still one value.

Run it#

Send the query by POST, with each parameter as a param_<name> field of the URL. Run from the repo root, with the query above saved as reconstruct_session.sql:

KEY="$(sed -n 's/^password=//p' .env.telemetry-reader.operator)"
curl -sS --user "operator:$KEY" --data-binary @reconstruct_session.sql \
  "http://127.0.0.1:10804/?http_wait_end_of_query=1&param_user=alice&param_session=SESSION_ID&param_after_at=2000-01-01%2000%3A00%3A00&param_after_source=&param_after_hash=0"

Replace alice and SESSION_ID with the user and session, URL-encoded. The query travels in the request body and the parameters in the URL; http_wait_end_of_query=1 makes a query over a limit answer with an error rather than part of a result (Read the Record).

The answer is one row per event, tool call, approval or preflight check, as tab-separated columns at, source, row_hash, user, kind, tool_use_id, terminal_session and detail.

Read the next page#

A page holds at most 500 rows. When a page holds exactly 500, take the last row’s at, source and row_hash as param_after_at, param_after_source and param_after_hash and send the query again. A page of fewer than 500 rows is the last one.
